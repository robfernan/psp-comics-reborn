# PSP Assets — Attribution & License Note

The PNG sprites in this directory (`textures/`, `fonts/`) were extracted from the
Sony PlayStation Portable (PSP) system firmware for **educational and personal use**.

They are used here to recreate the authentic PSP XMB menu aesthetic in a web-based
comics reader. This project is not affiliated with, endorsed by, or sponsored by Sony.

- `textures/` — UI chrome sprites: 9-slice menu items, top bar, face buttons, D-pad icons,
  scroll arrows, busy spinner, wave background, logos.
- `fonts/` — Bitmap font sheets (Helvetica Neue) from the PSP firmware. Kept for reference;
  the web app uses **Inter** (Google Fonts) as a scalable TTF equivalent.

If this repository is ever used commercially or in a public product, please review
Sony's IP guidelines or replace the sprites with original artwork.
